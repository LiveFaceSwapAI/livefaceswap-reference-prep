# Security Policy

Do not report a suspected vulnerability in a public issue.

Email [support@livefaceswap.ai](mailto:support@livefaceswap.ai) with:

- the affected URL, package version, or container tag;
- clear reproduction steps;
- the expected and observed behavior;
- the potential impact; and
- redacted logs or screenshots when they help explain the issue.

Remove access tokens, credentials, personal portrait images, payment information, and other sensitive data before sending a report.
