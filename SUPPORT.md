# Support

Use [GitHub Issues](https://github.com/LiveFaceSwapAI/livefaceswap-reference-prep/issues) for reproducible bugs, feature requests, and questions about this open-source reference image preprocessor.

For help with the LiveFaceSwap AI product or an account-specific matter, email [support@livefaceswap.ai](mailto:support@livefaceswap.ai). Do not include passwords, API keys, payment details, private portrait images, or other sensitive data in a public issue.

Security vulnerabilities should be reported privately as described in [SECURITY.md](SECURITY.md).
